Nasıl çalışır

Tara. Mühürle. Onayla çalıştır.

SealBox araya giren bir proxy değil. Sırları dosyalardan kalıcı olarak çıkarır. Hangi ajan, hangi editör ya da hangi dil olursa olsun diskte okunacak sır kalmaz.

  1. 01

    Tara

    Kurallar ve doğrulayıcılar parolaları, tokenları, API anahtarlarını, e-postaları, TCKN, IBAN ve telefonları bulur. sealbox seal --check hiçbir şeye dokunmadan rapor verir.

  2. 02

    Mühürle

    Sırlar AES-256-GCM kasaya taşınır. Kodda os.environ["X"] / process.env.X / System.getenv("X") kalır, kişisel veriler __SECURE_..__ etiketine dönüşür.

  3. 03

    Onayla çalıştır

    sealbox exec -- python app.py önce onay penceresi açar. Sırlar yalnızca o çalıştırmaya ortam değişkeni olarak verilir, çıktıdaki sırlar [GİZLİ:..] diye basılır.

  4. 04

    Paylaş

    Kasa şifreli olduğu için repoya girer. git push ile ekibe gider, onu yalnızca ekipteki GitHub hesapları açabilir.

$ sealbox seal --check
.env → .env.sealed: 1 değer kasaya taşınacak (DB_PASSWORD)
3 dosya tarandı (0.0 sn).
Diskte karalanmamış sır var. 'sealbox seal' çalıştırın.

Özellikler

Sırları bulur, saklar, izler.

Tek bir komut satırı aracı ve onun editör eklentisi. Bulut hesabı, sunucu ya da abonelik gerekmez.

Otomatik tarama

Regex kuralları, Luhn, IBAN mod-97, TCKN algoritması ve entropi kontrolüyle yanlış alarmı azaltır.

Şifreli kasa

.sealbox/project.vault, AES-256-GCM. Anahtar diskte değil, işletim sisteminin kimlik deposunda.

.env desteği

Gizli satırlar kasaya taşınır, .env silinir. Yerine yalnızca yer tutucu içeren .env.sealed kalır.

Her çalıştırmada onay

Onayı atlatan bir bayrak bilerek yok. Program sırlara ancak sen pencerede "evet" dediğinde ulaşır.

Çıktı süzgeci

Programın çıktısında ya da loglarında bilinen bir sır geçerse [GİZLİ:..] olarak basılır.

Python · JS/TS · Java

Kod, dilin kendi ortam değişkeni okumasına çevrilir. JSON/YAML/TOML ayarları karalanır ve raporlanır.

GitHub ile ekip

Arkadaşının GitHub'daki SSH anahtarına kilitli bir kopya oluşur. Ayrı bir şifre paylaşmak gerekmez.

Kurtarma kodu

Bilgisayar sıfırlanırsa kasayı geri açar. İstersen 3 parçaya bölünür, herhangi 2'si yeter.

Ekip paylaşımı

Gizli bilgilerini mesajla değil,
kasayla ilet.

Kasa repoda şifreli durur. sealbox team add arkadasim dediğinde SealBox github.com/arkadasim.keys adresinden arkadaşının SSH açık anahtarını alır ve kasa anahtarının ona özel kilitli bir kopyasını team.json'a yazar. Arkadaşın git pull yapınca kasa kendi SSH anahtarıyla açılır.

  • Sahip / üye rolleri. Sahipler kişi ekleyip çıkarabilir: --owner, team promote.
  • Çıkarınca anahtar yenilenir. team remove sonrası eski üye yeni kasayı açamaz, görmüş olabileceği değerler listelenir.
  • Sahte üye eklenemez. Her kayıt kasa anahtarından türetilen bir MAC ile imzalı.
  • Şifresiz SSH anahtarı reddedilir, çünkü ajan onu da okuyabilir.

Değerler hiçbir zaman açık hâlde ağdan geçmez; repoya yalnızca şifreli dosyalar girer.

GitHub'da güvende

Kasayı push'la. Sırları asla.

Sırların GitHub'dan yalnızca şifreli dosya olarak geçer. Her ekip arkadaşının anahtar kopyası kendi GitHub SSH anahtarıyla kilitlidir. Repo sızsa bile elde kalan, kilitli bir kutudur.

  1. 01

    SSH anahtarı oluştur

    Kişi başı bir ed25519 anahtarı, şifreli. SealBox şifresiz anahtarı kabul etmez, çünkü bilgisayardaki her program (ajanlar dahil) onu okuyabilir.

  2. 02

    GitHub'a ekle

    Açık yarısını (id_ed25519.pub) GitHub → Settings → SSH keys altına yapıştır. Zaten herkese açık olması için yapılmıştır: github.com/sen.keys adresinde görünür.

  3. 03

    Her arkadaşa ayrı kilit

    team add o açık anahtarı çeker ve kasa anahtarının bir kopyasını onunla kilitleyip team.json'a yazar. Onu yalnızca eşleşen gizli anahtar açar; o da arkadaşının bilgisayarından hiç çıkmaz.

  4. 04

    Push ve pull

    git push yalnızca şifreli dosyaları gönderir. git pull sonrası ilk çalıştırmada arkadaşının SSH şifresi bir kez sorulur, sonra anahtar onun işletim sistemi deposunda saklanır.

$ ssh-keygen -t ed25519                # sorulunca şifre koy
$ gh ssh-key add ~/.ssh/id_ed25519.pub # ya da: GitHub ayarları
$ sealbox team init --github my-name
$ sealbox team add teammate
$ git add .sealbox && git commit -m "vault" && git push

Git geçmişi kontrolü

Dosyayı temizlemek eski commit'leri temizlemez. sealbox history her commit'te kasadaki değerleri ve kodlanmış hallerini arar; değeri değil, yalnızca ad, commit ve dosyayı söyler. Push'lanmış olanları işaretler: onları yenile.

Commit kancası

sealbox hook install, kasadaki bir değeri içeren commit'i durdurur ve dosya:satır gösterir. Herkes kendi bilgisayarına kurar, repoya girmez.

Sürümler GitHub'da derlenir

Her sürüm GitHub Actions'ta test edilir, sonra PyPI'a güvenilir yayınlama (trusted publishing) ile gönderilir; GitHub'da hiçbir API anahtarı saklanmaz. Eklenti, ancak PyPI başarılı olunca Marketplace ve Open VSX'e çıkar.

Kurtarma

Anahtarı kaybetsen de kasa kaybolmaz.

Windows sıfırlandı, yeni bilgisayar aldın ya da profil bozuldu. Kasa anahtarı tek bir yerde dursaydı kasa sonsuza kadar kilitli kalırdı. SealBox'ta kasa anahtarının birden fazla kilidi var. Biri giderse ötekiyle açarsın.

  • recovery setup: 128 bitlik kurtarma kodu. Yalnızca pencerede gösterilir, terminale yazılmaz.
  • recovery shares: kodu 3 parçaya böler (Shamir). Herhangi 2 parça yeter.
  • recovery export: USB ya da bulut için kurtarma kiti. Kod olmadan açılmaz.
  • recovery restore: kod, 2 parça ya da kit ile anahtarı geri getirir.
